## 👋 About Me

I'm a Computing undergraduate at **SLIIT**, building full-stack web applications with a growing focus on integrating AI into practical, real-world tools. I care about clean architecture, thoughtful UI/UX, and following a proper SDLC — requirements → design → implementation — rather than jumping straight to code.

- 🎓 Studying Software Engineering / IT at SLIIT
- 💻 Comfortable across the stack — from Postgres schemas to pixel-perfect Tailwind UI
- 🤖 Exploring AI integrations: RAG pipelines, local LLMs, and applied ML
- 🌱 Currently deepening my knowledge of **ASP.NET Core** and enterprise-style backend architecture
- 📍 Based in Sri Lanka
